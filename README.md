# Автоматизированные тесты для сайта Хабр

## Описание проекта
Проект представляет собой автоматизированные тесты для веб-сайта Хабр. 
В качестве фреймворка для тестирования использовался Playwright.

## Запуск тестов
Для запуска тестов используйте 
утилиту Playwright Test for VSCode
ВНИМАНИЕ! при выполнении команды:
```bash
npm run test:play

# тесты проходят с ошибками. 

# Для создания отчетов о выполненных тестах используется Allure
Для запуска отчета используйте команду:
```bash
npm run allure:open
